# Tucker's stag

The page for the lads: plan, villas, packing list, rules, help numbers and photos.

Live at https://forsterjoea-ux.github.io/tucker-stag/

## Editing the page (admin only)

Everything on the page comes from `data.json`. Only people with write access to this repo can change it.

To edit from your phone:

1. Make a token at https://github.com/settings/personal-access-tokens/new
   - Repository access: **Only select repositories** → `tucker-stag`
   - Permissions: **Contents → Read and write**
   - Expiry: a week or two is plenty
2. Open the site, scroll to the bottom, tap **Admin**, paste the token.
3. Edit buttons appear on the notice, every plan item, the villas, packing list, rules, contacts and photos. Tap **Add to Friday** (etc.) to fill a free-time slot.
4. Changes are live for everyone about a minute after you save. Tap **Lock** when you're done.

The token is saved on that phone only. Nobody else can edit without their own token.

You can also just edit `data.json` on github.com.
